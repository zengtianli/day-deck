## 九问草案

1. **功能与主要问题**：已有 Notihub 服务的用户需要在离开 Mac 后看今天要做什么、当天通知的总结与时间线，并随手记下想法；App 提供待办分组、日期选择、搜索、正文阅读、随手记提交与错误恢复。待办状态和随手记写既有云服务，只有收到有效回执才显示保存；系统提醒事项是用户主动操作的本机流程。
2. **目标用户**：已有通知复盘工作台及服务访问资格的个人使用者，通常在早晨、出门时和晚间复盘；当前不是可公开注册的多用户服务。正式客户端服务地址固定，不能把开源用户可自行改源码配置说成现有 App 内支持任意服务。
3. **独立贡献**：将同一份复盘数据适配触屏、小屏、iPad/Vision 宽屏及配对手表摘要，提供可读的陈旧度、失败保留草稿、明确区分云端写入与交给 Mac 排队的动作。此次新增原生设置、启动页偏好、仅配置的可选 iCloud 同步及真实商店版本查询；不把性能旧数据当作当前发行包实测。
4. **测试与反馈**：当前证据含 Swift 核心测试54项、真实模拟器四平台启动，以及 product_basics 的真实 App 内离屏设置和隔离往返54个严格检查；身份和覆盖见 handoffs/all-product-basics-20261014.md。没有可证的外部 beta 反馈统计，不编造受测人数或意见；真机和苹果跨设备 iCloud 传输未以本轮证据证明。当前素材和资源仍有待验项。
5. **独立产品还是套件**：这是 Notihub 工作台的移动客户端，属于同一产品家族；Mac 菜单栏客户端是 `notifhub-bar-mac`。移动端不再采集一份系统通知或另建账本，与 Mac 共用服务数据。
6. **为何没有并入其他 App**：触屏与配对手表阅读使用不同系统 target、权限和生命周期，Mac 菜单栏采集器无法直接作为 iPhone 应用运行；同一移动工程覆盖 iPhone/iPad/Vision，手表仅接收摘要，避免为相同移动任务再建相似独立 App。
7. **共用代码与素材**：与同族 Mac 共用 Notihub 品牌、图标及云端契约；共享 AppConfiguration/AppLifecycle 负责配置验证、备份、同步和版本检查，RemoteUI/LaneSignal/PlatformCompat 负责远端说明文字与平台/诊断基础设施。业务模型、读写回执、待办分组、提醒事项映射及移动视图在本产品维护。共用基础设施不包含他人的业务数据或模板化账号内容。
8. **第三方代码、SDK与内容**：客户端使用 Apple SwiftUI/UIKit、Foundation、EventKit、WatchConnectivity、WidgetKit、系统钥匙串与 iCloud 系统服务，未发现广告或第三方分析 SDK；SwiftPM 未登记额外第三方客户端依赖。Notihub 自有公开源码快照采用 MIT，见 https://github.com/zengtianli/notihub/tree/main/ios；截图夹具由本产品维护且明确合成。运行内容来自用户获授权的既有服务，不随包提交，也不作为审核附件；审核访问需要另外验证的隔离合成数据。
9. **提供者及提交主体**：源码版权、维护者与 ASC 工具现有联系人对应曾田力/Tianli Zeng，这是开发者维护的自有 Notihub 产品；不是替客户批量提交模板应用。提交前联系人仍从原受保护 ASC 配置读取，不能把个人电话号码或审核凭据写入公开材料。

## 仍需落实的正式包条件

- **审核业务访问**：Sources/API.swift 固定 `https://day.tianli.cyou` 且只允许该主机，Gate 的登录闸固定；DemoData/DemoFeed 仅在 DEBUG，普通 Release 不存在演示通路。当前凭据名称检查未找到 Notihub 专用审核凭据；不能给 Apple 主人现有访问密码，也不能拿本机 URLSession 夹具或 DEBUG 演示声称 Release 可审。
- **服务隔离边界**：Notihub Cloud 的 api.py 明确一进程/一域名/一数据库，不接受客户端 tenant；在本组件里改变 store.demo 不能产生隔离数据。创建/部署另一服务实例属于该服务组件工作，不能在此次 iOS 仓内改线上服务、DNS 或 authgate。需由服务责任方给出真实隔离入口与受保护审核凭据，再验证客户端的实际登录、读写与恢复。
- **隐私与支持页**：共享 products.yaml 新增本产品实际隐私/支持文案，只是源材料；需要原 chapter promo/Lintel 路径生成、发布并匿名回读后，才可填 ASC URL。对旧 Mac 的 privacy/support URL 的匿名请求均返回403，不能当作已核可访问的本产品页面。
- **商店资料**：原 asc_listing.py 入口现在可识别本产品 store 源，但仍缺最终包、截图、已验证审核凭据和实际发布页面；store.demo 只引用尚未配置的专用受保护变量，固定 --review 会在缺凭据时停止，不会误写“无需账号”。不运行 --all 或 --submit 碰运气。
- **输入绑定**：复用有效旧验收，只补当前素材/资源及实际改动涉及的回归；不重建整页或整套视频来补文字，不把固定脚本缺口改为免验。
